power_spectra_plots.ipynb : 
    - This is the original script used to test that the variables behave as expected, for both A_d and ell_d
    - Includes plots for TT, TE, EE, and BB spectra with different values ("Power Spectra, and Parameter Effects")
    - Produces the various rescale .ini files in my_analysis/ and the outputs in output/
    - Includes plots for 1D likelihood scans from Planck_1D_parameter_scan.py and ACT_1D_parameter_scan.py ("1D Parameter Scans with Planck and ACT")

Planck_1D_parameter_scan.py :
    - Performs 1D parameter scans independently across A_d and ell_d with Planck
    - Produces Planck_scan_ell_d.txt and Planck_scan_A_d.txt

ACT_1D_parameter_scan.py :
    - Performs 1D parameter scans independently across A_d and ell_d with ACT
    - Produces ACT_scan_ell_d.txt and ACT_scan_A_d.txt
